# Pizza_Sale_Project Overview

This project analyzes pizza sales data using SQL to uncover key insights about business performance. By running SQL queries, we identify total revenue, order trends, top-selling pizzas, and customer preferences. The goal is to transform raw transactional data into meaningful insights that help in decision-making, improving sales strategies, and enhancing customer satisfaction.

## Questions

Basic:

What is the total number of orders placed?

What is the total revenue generated from pizza sales?

Which is the highest-priced pizza?

What is the most common pizza size ordered?

Which are the top 5 most ordered pizza types?

Intermediate:

What is the total quantity of each pizza category ordered?

How are orders distributed by hour of the day?

What is the category-wise distribution of pizzas?

What is the average number of pizzas ordered per day?

Which are the top 3 pizza types based on revenue?

Advanced:

What is the percentage contribution of each pizza type to total revenue?

How has cumulative revenue grown over time?

Which are the top 3 pizzas based on revenue in each category?

## Conclusion

The SQL analysis of pizza sales data revealed valuable insights into customer behavior and sales performance. Revenue trends, order distribution, and category analysis highlighted the best-performing pizzas and identified areas of improvement. Basic, intermediate, and advanced queries together provided a complete picture of business operations.

This project shows how SQL can turn raw data into actionable insights, while dashboards can enhance visual understanding. Overall, it emphasizes the importance of data-driven decisions for business growth and customer satisfaction.
